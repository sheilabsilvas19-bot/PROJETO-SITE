O site Sheila Silva | Personal Trainer foi desenvolvido com o objetivo de apresentar serviços de treinamento físico de forma profissional, moderna e acessível. A plataforma foi construída utilizando HTML e CSS, oferecendo uma interface organizada e intuitiva, com informações sobre a profissional, modalidades de treinamento presencial e online, além de formulários para cadastro, anamnese e avaliação inicial dos alunos. O projeto busca unir tecnologia e Educação Física, facilitando a comunicação, o atendimento e o acompanhamento dos clientes.
